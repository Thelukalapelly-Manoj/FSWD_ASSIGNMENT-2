\# FSWD Assignment 2



This repository contains three independent React applications developed using React and Vite.



\## Projects



\### 1. Product Card

\- Reusable ProductCard component

\- Props for name, price, image, and rating

\- Default parameter values

\- Four different product cards



\### 2. Button Styling

\- Reusable Button component

\- Primary, Success, and Danger variants

\- Inline styles and external CSS

\- Hover effects



\### 3. Stopwatch

\- Start, Pause, and Reset buttons

\- Displays minutes and seconds

\- Uses React `useState` and `useEffect`

\- Cleans up the interval when necessary



\## Technologies Used

\- React

\- JavaScript

\- CSS

\- Vite



\## How to Run

Open a terminal inside the project you want to run, then execute:



```bash

npm install

npm run dev

```



Repeat these commands inside the respective project folder for each assignment.
